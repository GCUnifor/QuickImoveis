# QuickImoveis

Plataforma imobiliária desenvolvida para conectar **compradores** e **corretores** em uma experiência digital simples, intuitiva e moderna.  
O projeto reúne diferentes frentes de desenvolvimento, contemplando **backend**, **frontend web** e **aplicação mobile**.

## Visão geral

O **QuickImoveis** foi criado com o objetivo de facilitar a busca, recomendação e divulgação de imóveis, oferecendo recursos tanto para usuários interessados em comprar/alugar quanto para corretores que desejam cadastrar e gerenciar seus imóveis.

A aplicação conta com:

- autenticação de usuários
- cadastro de comprador e corretor
- recuperação de senha
- listagem de imóveis
- recomendações personalizadas
- visualização de detalhes dos imóveis
- favoritos
- área de perfil
- fluxo mobile com onboarding e navegação por abas
